What's built in

Four relationships, tested and confirmed in every batch

These aren't hidden in the noise — they're the reason ClaimsForge exists. Every dataset it forges encodes the same four directional relationships between driver risk factors and claim severity, so your regression, GLM, or classroom exercise has something real to recover.

Driver age

Smaller claims

Older drivers tend to drive more cautiously — claim size falls as age rises.

Gender

Larger claims (male)

Male drivers are linked in the literature to higher-speed, higher-impact driving.

Driving experience

Smaller claims

More experienced drivers are better at avoiding serious accidents.

Past claims count

Larger claims

Drivers with more claims history run larger claims too, not just more frequent ones.

How it works

The generator runs in your browser

No accounts, no uploads, no server round-trip. Pick a record count and a seed, and a deterministic model — frequency of claims, then severity of the ones that happen — runs entirely client-side and hands you a CSV.

What's next

A Django backend, when there's a reason for one

The generation logic lives in a framework-free module so it can be ported into a real backend later — batch generation, an API for other tools to call, saved presets — without redesigning the site. For now, the browser is the backend.
