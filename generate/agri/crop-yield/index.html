The tool

Forge a Crop Yield dataset

Choose how many plot-season records you want and a seed. The same two numbers will always produce the same dataset — write the seed down and cite it in your methodology chapter.

Previewing without an account — capped at 20 rows, 1 request per IP every 6 hours, no citation/checksum/manifest. Log in or create a free account for up to 100 rows plus full provenance.

Capped at 20,000 — the API generates synchronously (see ROADMAP.md Phase 1 for the planned async path beyond that).

Two-stage additionally computes a yield-loss-percentage measure for shortfall plots — the three pest_disease_outbreak/delayed_planting/yield_loss_pct columns only exist in this mode. Single-stage reports whether a shortfall occurred, no severity fields at all.

Advanced: customize the model

Same directional relationships described in the methodology — strengthen, weaken, or rebalance them here without touching any code. Defaults are illustrative, anchored against general agronomy and crop-water-stress literature, not derived from real farm-monitoring data.

Shortfall probability

Crop type is table-rated off the crop-base-shortfall-rate anchor (not adjustable here); these loadings multiply on top of it. Active in both stage modes.

Yield-loss severity two-stage only

Only computed for shortfall plots when stage mode above is two-stage.

Cite this dataset
